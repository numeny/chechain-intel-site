# 销售漏斗与系统架构

日期：2026-10-23

## 一、当前架构

```
parser/data/gan.db（只读）
        │
        ▼
export_intel（Python）
  ├─ data.py     读取已发布企业/品牌/集团/信号
  ├─ excel.py    生成 Excel（企业、品牌代理、集团关系、说明）
  ├─ pdf.py      生成 PDF 摘要 / 日本信号简报
  ├─ sample.py   10 条脱敏样本 + 升级 CTA
  └─ cli.py      au/br/jp × full/sample
        │
        ▼
deliverables/（Excel + PDF）
        │
        ├──► site/（静态产品页，展示覆盖、样本、定价、FAQ）
        ├──► sales/listings/（闲鱼、猪八戒、小红书文案）
        └──► sales/articles/（知乎/公众号长尾内容）
        │
        ▼
客户咨询（闲鱼/知乎/猪八戒私信）
        │
        ▼
人工成交（微信/闲鱼收款）→ 交付 → CRM 记录 → 7 天售后 → 转介绍
```

## 二、组件职责

| 组件 | 职责 | 不做什么 |
|---|---|---|
| `parser` | 采集、解析、审核、发布公开数据 | 不参与销售、不存客户信息 |
| `export_intel` | 只读导出、脱敏、生成销售物料 | 不写数据库、不采集个人信息 |
| `site/` | 信任建设、样本下载、定价说明 | 不接支付、不收集表单 |
| 平台 listings | 获取搜索流量、承接咨询 | 不放联系方式、不做虚假承诺 |
| 内容文章 | SEO/长尾获客、教育市场 | 不刷量、不诱导分享 |
| CRM CSV | 记录线索、阶段、下一步 | 不存敏感个人信息 |
| 人工交付 | 收款、发文件、答疑、售后 | 不承诺成交、不卖隐私 |

## 三、数据流

1. `parser` 每周更新公开数据并审核发布。
2. `export_intel` 读取 `status='published'` 记录，生成 Excel/PDF。
3. 样本包脱敏（隐藏门牌号、来源查询参数），加升级 CTA。
4. 正式包按版本命名（`australia_dealers_YYYY-MM-DD.xlsx`）。
5. 客户从站点/平台下载样本 → 私信 → 人工确认需求 → 收款 → 发正式包。
6. 成交与交付记录写入 `sales/ops/crm.csv`。
7. 订阅客户每月收到更新包与变更清单。

## 四、UI 原则

1. **先给样本，再谈价格**：首屏有“免费看 10 条样本”，降低信任门槛。
2. **透明字段**：明确“有什么、没有什么”，标准包不含联系方式写在首屏和定价区。
3. **来源可核验**：样本表带来源链接，PDF/Excel 带来源列。
4. **不制造虚假紧迫**：首月 1,999 元限前 5 名，是真实可执行的促销，不是倒计时骗局。
5. **移动优先**：390px 宽度下导航、定价、表格可读；表格可横向滚动。
6. **不用暗黑模式套路**：不预勾选、不隐藏退款规则、不伪造评价。

## 五、失败模式与应对

| 失败模式 | 征兆 | 应对 |
|---|---|---|
| 站点有访问无咨询 | 样本下载多、私信少 | 在样本 PDF 加 CTA；在定价区加“先看样本”；检查按钮位置 |
| 有咨询无成交 | 问价后消失 | 用 99 元试用降低门槛；发脱敏案例；解释“不含联系方式” |
| 嫌贵 | “别家免费/更便宜” | 对比“来源可核验 + 集团关系 + 更新时间”；推 99 元样本 |
| 要联系方式 | “没有联系方式没用” | 推定制 3,000 元起；只核验企业官网公开邮箱/总机 |
| 数据错误 | 客户指出门店已关闭 | 48 小时内更正；记录来源；更新版本 |
| 平台限流/下架 | 商品审核不通过 | 改标题/类目；转猪八戒/知乎；保留站点 |
| 交付占用时间 | 每天超过 2 小时 | 模板化；限制定制范围；提高定制价格 |

## 六、后续演进

1. **联系信息加购**：只做企业官网公开邮箱/总机，人工核验，1,000-2,000 元/国。
2. **订阅自动化**：每月自动生成变更清单（新增/关闭/换牌），邮件/微信推送。
3. **轻量 CRM**：从 CSV 升级到 SQLite/Notion，记录线索与交付。
4. **多语言**：英文版站点，面向海外买家/咨询机构。
5. **API/数据授权**：面向企业客户按年授权，价格 1-5 万/年。
6. **合规审计**：来源清单、删除请求、数据处理记录。

## 七、当前边界

- 无后端、无支付、无用户系统；交易在平台/微信完成。
- 无自动外呼/冷邮件；只做平台内被动获客与内容营销。
- 数据覆盖仅澳洲/巴西/日本，品牌以 BYD/MG/Chery 为主。
- 标准包不含联系方式；定制可核验公开企业联系方式。
