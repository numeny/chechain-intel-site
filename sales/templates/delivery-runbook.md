# 交付与运营手册

## 一、每日 30-60 分钟固定动作

1. 早上看闲鱼/猪八戒/知乎私信，先回“样本/价格/交付”三类问题。
2. 对已付款客户，按《交付话术模板》发文件。
3. 晚上记录当天数据：咨询数、加微数、试用单、正式单、营收。
4. 每周日复盘：哪个标题带来咨询、哪个价格成交、哪个渠道无效。

## 二、收款到交付（30 分钟内）

1. 确认订单：国家、版本、交付方式、邮箱/网盘。
2. 确认收款（闲鱼订单/微信/支付宝）。
3. 从 `deliverables/` 取对应文件：
   - 澳洲：`australia_dealers_2026-10-23.xlsx` + `.pdf`
   - 巴西：`brazil_dealers_2026-10-23.xlsx` + `.pdf`
   - 日本：`japan_signals_2026-10-23.pdf`
   - 试用：`sample/` 下对应文件
4. 发网盘链接 + 交付话术。
5. 请客户确认三点：能打开、字段符合预期、数量级对得上。
6. 归档：订单截图、客户需求、交付版本。

## 三、每周更新流程（订阅客户）

在 `parser` 项目中：

```powershell
# 1. 抓取并解析全部源（串行）
.venv\Scripts\python -m gan.cli run-all

# 2. 打开 http://127.0.0.1:8000/admin 审核新数据
# 3. 重建索引（如使用 Meilisearch）
.venv\Scripts\python -m gan.cli index rebuild
```

回到 `new_day`：

```powershell
.venv\Scripts\python tools\export.py --country au --kind full
.venv\Scripts\python tools\export.py --country br --kind full
.venv\Scripts\python tools\export.py --country jp --kind full
```

将新文件命名中的日期更新，发给订阅客户，并附一句“本期新增/变更 X 条”。如果抓取失败，沿用上一版并在交付说明中标注。

## 四、退款与争议

- 未发货：全额退。
- 已发货：虚拟商品不支持退款；可免费换一次版本，或针对错误条目更正。
- 定制单：按合同执行；初稿后 2 个工作日内提修改意见，含 1 次修改。
- 客户要求删除/更正：48 小时内核实并处理，同步更新版本。

目标：
- D7：≥3 个咨询；
- D14：≥1 个付费，营收 ≥1,000 元；
- D21：≥3 个付费，营收 ≥3,000 元；

## 六、止损与调整

- D7 咨询 <3：换标题/封面，增加 99 元试用曝光，去相关知乎问题下回答。
- D14 无付费：降价 30%，把定制单放到猪八戒首页，尝试 Fiverr。
- D30 未达 5,000 元：暂停扩张，复盘渠道；保留订阅续费，不投广告。
- 任何阶段：不碰个人信息、不买来源不明名单、不做虚假承诺。

## 七、合规检查清单（每次交付前）

- [ ] 文件内“说明”页含来源、日期、免责声明。
- [ ] 标准包不含联系人/邮箱/手机号。
- [ ] 来源链接可点击；失效链接不超过 10%。
- [ ] 客户用途不涉及违法或侵犯第三方权益。
- [ ] 保留订单与交付记录，收入依法申报。
